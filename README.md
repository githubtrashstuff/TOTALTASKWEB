# TOTALTASK

Канбан и календарь для личных задач: https://githubtrashstuff.github.io/TOTALTASKWEB/

Язык интерфейса: English (по умолчанию), Русский, Deutsch, 中文. Меняется в настройках и на стартовом экране.

## Где хранятся задачи

При первом запуске сайт предлагает два способа:

- **Локально** (по умолчанию): задачи лежат в localStorage этого браузера. Без аккаунта, работает без сети. Другие устройства и Claude их не видят. В настройках есть скачивание резервной копии.
- **Бесплатная синхронизация через GitHub**: задачи лежат в вашем собственном (обычно приватном) репозитории GitHub, а сайт читает и пишет их через GitHub API с вашим токеном. Токен хранится только в вашем браузере.

## Как подключить GitHub

1. Создайте репозиторий для задач (можно пустой, недостающие файлы сайт создаст сам).
2. Создайте fine-grained токен: github.com/settings/personal-access-tokens/new → доступ только к этому репозиторию → Permissions → Contents: Read and write.
3. Откройте сайт, укажите владельца, репозиторий и токен.

## Формат данных

- `data/board.json` — колонки доски.
- `data/inbox.json` — задачи без даты.
- `data/weeks/ГГГГ-Www.json` — задачи одной ISO-недели.
- `data/reports/latest.md` — отчёт последнего анализа (показывается по кнопке АНАЛИЗ).

Весь сайт: один файл `index.html`, без сборки.

## Как сохраняются изменения

- Пока вы двигаете карточки, пишете или держите открытым окно задачи, ничего не отправляется. Действия копятся в браузере и не теряются при закрытии вкладки.
- Сохранение происходит после паузы (по умолчанию 1 минута), при уходе со вкладки или по нажатию на плашку «Не сохранено» в шапке.
- Все изменённые файлы уходят **одним коммитом**. Заголовок перечисляет классы действий (`TOTALTASK: перенос ×3, выполнено, правка`), в теле по строке на действие.
- Коммиты сайта за час или день можно объединять в один (настройка). Объединяется только последний коммит сайта, если после него никто ничего не коммитил.
- Если файл тем временем изменил Claude или другое устройство, сайт берёт свежую версию и накладывает свои правки поверх, поле за полем.
- Без сети сайт открывается с последними загруженными данными, правки отправятся, когда сеть появится.
