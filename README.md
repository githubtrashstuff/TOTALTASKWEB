# TOTALTASK

Канбан и календарь для личных задач: https://githubtrashstuff.github.io/TOTALTASKWEB/

Сайт не хранит задачи. Они лежат в вашем собственном (обычно приватном) репозитории GitHub, а сайт читает и пишет их через GitHub API с вашим токеном. Токен хранится только в вашем браузере.

## Как подключиться

1. Создайте репозиторий для задач (можно пустой, недостающие файлы сайт создаст сам).
2. Создайте fine-grained токен: github.com/settings/personal-access-tokens/new → доступ только к этому репозиторию → Permissions → Contents: Read and write.
3. Откройте сайт, укажите владельца, репозиторий и токен.

## Формат данных

- `data/board.json` — колонки доски.
- `data/inbox.json` — задачи без даты.
- `data/weeks/ГГГГ-Www.json` — задачи одной ISO-недели.
- `data/reports/latest.md` — отчёт последнего анализа (показывается по кнопке АНАЛИЗ).

Весь сайт: один файл `index.html`, без сборки.
